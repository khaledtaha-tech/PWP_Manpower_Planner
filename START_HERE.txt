PWP MANPOWER PLANNER — START HERE
================================

CURRENT SYSTEM
--------------
Node.js Web App on Hostinger with MySQL, bcrypt passwords and JWT sessions.
Firebase and Render are not used by the running application.

LOCAL CHECK
-----------
1. Install Node.js 22.
2. Run: npm install
3. Copy .env.example to .env and enter the MySQL and JWT values.
4. Run: npm test
5. Run: npm start
6. Open: http://localhost:3000

HOSTINGER
----------
1. Keep the existing MySQL tables and data.
2. Configure the variables listed in .env.example in the Node.js app settings.
3. Build command: npm install
4. Start command: npm start
5. Deploy the latest GitHub commit.
6. Open /api/health and confirm database is Connected.

EXCEL IMPORT
------------
1. Download the Excel template from the 14-Day Plan screen.
2. Fill the seven Plan columns without renaming them: Line ID, Machine Name,
   Sequence, Status, Product, Duration and Workers/Day.
3. Import and review validation, preview, and any New Machines count.
4. Missing Line IDs are added automatically; Machine Name is shown to the
   Production Manager and Lists supplies the remaining machine metadata.
5. Do not add Crusher rows to Plan; control it with Floating/Mandatory mode.
6. Floating is normal surplus-only operation; Mandatory is the exception.
7. Choose Update or Replace, apply to Draft, then press Save.
8. Import never publishes automatically.

NOTICE LOGIC
------------
With a three-day notice, a decision issued on day 1 becomes effective on day 4.
The target protects the highest Agency requirement across days 4, 5 and 6. The
next review is day 4 for an action effective on day 7, and so on.
